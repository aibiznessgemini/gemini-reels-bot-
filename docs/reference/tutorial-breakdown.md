## 6. Design system
- **Color palette (sampled from keyframes):**
  - **Primary canvas background (diagonal linear gradient):** `#2E50EB` (top-left) → `#2C4BDA` (mid) → `#1932AB` (bottom-right) — signature energetic SaaS-tutorial royal blue backdrop.
  - **Primary accent / highlight:** `#FFBF36` (warm golden yellow) — underlines, progress bars, PiP frame border (`3px`), UI highlight boxes, numbered step circles.
  - **Card / pill surface:** `#FFFFFF` / `#FDF9FF` — floating callout pills, info cards, prompt badges.
  - **Dark surface (code / YT Studio):** `#1A1D26` (code editor), `#0F0F0F` (YouTube Studio dark UI).
  - **Primary text on blue:** `#FFFFFF` (headings, step titles, big figures).
  - **Primary text on white pills/cards:** `#111827` / `#0F172A` `[CONFIDENCE: high]`.
  - **Semantic accents:** Success green `#22C55E` (checkmarks, credit bars, growth bars); Alert red `#EF4444` (red X badges, flatline graph); Claude brand terracotta `#D97757` `[CONFIDENCE: high]`.
- **Typography:**
  - **Primary UI/Headline font:** Looks like **Inter** or **SF Pro Display / Plus Jakarta Sans** (geometric grotesque sans-serif, tight tracking) `[CONFIDENCE: high]`.
  - **2 Free Google Fonts alternatives:** `Inter` (closest match) and `Plus Jakarta Sans` (or `DM Sans`).
  - **Code font (`CLAUDE.md` / Remotion code):** `JetBrains Mono` or `Fira Code` `[CONFIDENCE: medium]`.
  - **Weights & sizes:** Hero numbers/Step titles: `700–800` Bold/ExtraBold, `10%–12%` of frame height (`72–86px` at 720p); Section headlines: `700` Bold, `6%–7%` H (`44–50px`); Floating caption pills: `600–700` SemiBold/Bold, `2.6%–3.2%` H (`19–23px`).
  - **Case & spacing:** Sentence case everywhere (lowercase casual phrasing in pills, e.g., `the next steps`, `paper cut out`); tight letter-spacing (`-0.02em` on headlines); soft drop shadow on white pills (`0 8px 24px rgba(0,0,0,0.18)`), no heavy black text strokes.
- **Illustration style:** Clean flat/modern SaaS vector UI (`2D`), subtle `12px–16px` rounded corners on all windows/cards, soft ambient drop shadows, no grain or vignette on the blue canvas. (The *embedded* Remotion examples use separate styles: flat 2D stick-figure, paper cut-out, pixel art, ink wash, etc.)
- **Recurring elements:**
  - **Host PiP box:** Rounded square (`22%` W × `44%` H, `14px` border-radius) anchored right (`75%` X, `28%` Y) with a `3px` `#FFBF36` golden border and drop shadow.
  - **Floating macOS windows:** Screen recordings always sit inside rounded-corner frames (`84%–86%` W) floating over the `#2E50EB`→`#1932AB` blue canvas (never raw full-bleed desktop).
  - **Yellow highlight frames:** Glowing `#FFBF36` rounded rectangles (`2px–3px` stroke + soft yellow outer glow) drawing attention to clicks/metrics.
  - **Chapter title cards:** Centered `Step N` + animated `#FFBF36` horizontal underline + subtitle.
- **Lighting & color grading:** Talking-head footage (`00:00–00:05` and PiP) uses soft warm-neutral indoor key light (`~4500K`), natural contrast, slight background blur, warm lamp accent behind left shoulder. Motion graphics are crisp, high-contrast digital sRGB.

## 7. Motion language
- **Typical animation types:**
  - **Scale + fade pop-in** for pills, cards, and badges (`scale 0.85→1.0`, `opacity 0→1`).
  - **Horizontal draw-on** for `#FFBF36` underlines, progress sliders, and growth curves.
  - **Smooth cursor-tracked zoom** (`100%→150%`) inside Screen Studio–style screen recordings.
  - **Slide-in/out window transitions** when switching between Google Docs, Chrome, and Claude Code.
  - **Number counter roll-up** (`$2,631 → $10,000` at `01:05`).
- **Easing curves & durations:**
  - UI pop-ins / cards: `cubic-bezier(0.34, 1.56, 0.64, 1)` (subtle ease-out-back overshoot), `0.22s–0.30s`.
  - Window slides & Screen Studio zooms: `cubic-bezier(0.22, 1, 0.36, 1)` (fast-out, smooth settle), `0.30s–0.45s`.
  - Line/bar draw-ons: `cubic-bezier(0.4, 0, 0.2, 1)`, `0.50s–1.20s`.
- **Editing rhythm:**
